# CLAUDE.md

Guidance for working in the **tracelabel** repo. Read this before editing.

## What this is

tracelabel is a local-first, keyboard-fast labeling tool for LLM/agent traces and
documents. It ships as a single Python wheel that bundles a FastAPI server, a
prebuilt React SPA, and a per-project SQLite database — `uvx tracelabel demo` opens a
browser labeling UI over your own traces. Single-player, no accounts, no cloud, no
telemetry.

## Coding standards (follow these on every change)

These are the house rules. When in doubt, they win.

1. **Write for a junior engineer.** Code should be understandable by someone new to
   the project without help. Prefer obvious names, short functions, and straight-line
   logic over cleverness.
2. **Reach for the standard library / built-ins first.** In Python, TypeScript, and
   everywhere else, use a built-in or a well-established library primitive before
   hand-rolling logic. Only hand-roll when nothing standard does the job.
3. **Python: class-based OOP with constructor dependency injection.** Prefer classes
   whose collaborators are passed into `__init__` (with sensible real defaults), not
   module globals or hidden singletons. This is the existing pattern — see
   `ServeCommand.__init__` in `src/tracelabel/cli/commands.py` and
   `ConfigResolver.__init__` in `src/tracelabel/config/resolver.py`.
4. **Simplicity and readability win every trade-off.** Choose the version that is
   easier to read.

## Tech stack

- **Backend:** Python ≥3.10 · FastAPI + uvicorn · Pydantic v2 · Typer (CLI) · stdlib
  `sqlite3`. Optional `litellm` (the `[ai]` extra). Build backend: hatchling.
- **Frontend** (`frontend/`): React 18 + TypeScript (strict) · Vite · Tailwind ·
  TanStack Query · vendored shadcn/ui primitives. State is React Context +
  `useReducer`; UX is keyboard-first (`frontend/src/keyboard/useKeyboard.ts`).
- **Tooling:** uv (Python) and npm (frontend). ruff + mypy (`strict`, backend only).
  e2e via Playwright in `e2e/`.

## Commands

Run from the repo root.

| Task | Command |
|---|---|
| Install deps | `uv sync --extra dev` then `npm --prefix frontend ci` |
| Run the app | `uv run tracelabel demo --no-browser` (UI at http://127.0.0.1:8377) |
| Python tests | `uv run pytest -q` |
| Lint / format Python | `uv run ruff check src tests` · `uv run ruff format` |
| Type-check Python | `uv run mypy src/tracelabel` |
| Build frontend | `npm --prefix frontend run build` |
| Frontend tests | `npm --prefix frontend test` (vitest) |
| Type-check frontend | `npm --prefix frontend run typecheck` |
| Frontend live dev | `npm --prefix frontend run dev` (Vite :5173, proxies /api → :8377) |
| e2e tests | from `e2e/`: `npm ci` then `npx playwright test` (needs the SPA built + package installed) |

There is no Makefile/justfile, and **no frontend linter/formatter** — don't invoke
`npm run lint`/`format`; those scripts don't exist.

## Repo layout

- `src/tracelabel/` — backend (src-layout). Key packages: `cli/` (Typer app +
  command classes), `api/` (FastAPI factory, routes, `LabelingService`), `config/`
  (task-config models/loader/resolver), `ctf/` (canonical trace format), `db/`
  (sqlite repositories + migrations + locking), `imports/` + `imports/adapters/`
  (ctf/adk/datadog/documents/loose), `exporting/`, `suggestions/` (LLM prefill).
- `src/tracelabel/static/` — **generated** SPA build output; gitignored.
- `frontend/` — React SPA source (`frontend/src/{components,api,state,lib,keyboard}`).
- `tests/` — pytest (flat; helpers in `tests/helpers.py`; golden fixtures in `tests/golden/`).
- `e2e/` — standalone Playwright package.
- `docs/design/00`–`10` — the authoritative spec; start at `00-overview.md`. `03-config.md`,
  `04-cli.md`, `05-http-api.md`, and `06-frontend.md` are retired (superseded by the
  workspace/project/task model — see `00-overview.md` and `docs/refactor-plan.md`).

## Critical rules (enforced, not suggestions)

- **Never edit or commit `src/tracelabel/static/`.** It's regenerated by
  `npm --prefix frontend run build`, which wipes and recreates it. A missing
  `static/index.html` fails CI and release.
- **No `dangerouslySetInnerHTML`.** CI greps `frontend/src/` and fails if it appears;
  untrusted HTML renders only inside a sandboxed iframe (`components/renderers/HtmlFrame.tsx`).
- **API keys come from env vars only.** An `api_key:` in config is a hard error; keys
  are never logged or written to the DB. The server binds `127.0.0.1` only — no auth,
  no telemetry, ever.
- **Raise typed errors, not bare `SystemExit`.** Use `TraceLabelError` subclasses from
  `src/tracelabel/errors.py`; `cli/app.py` `run()` maps them to process exit codes.
- **Pydantic config uses `extra="forbid"`** — unknown/typo'd YAML keys are hard errors.
- **Imported content is immutable** — stored byte-for-byte, never reformatted.
- `frontend/src/api/types.ts` is a hand-synced copy of the backend's Pydantic models
  (`src/tracelabel/api/models.py`) — the source of truth for the HTTP contract; change
  it only to track that file.

## Testing conventions

- **Python:** pytest (+ hypothesis for property tests, httpx for the API, Typer
  `CliRunner` for the CLI). No `conftest.py`; shared helpers live in `tests/helpers.py`.
  Tests construct services directly via constructor DI. mypy runs `strict` on `src/` only.
- **Frontend:** vitest + `@testing-library/react`, co-located `*.test.tsx`. Mock the API
  module with `vi.mock("@/api/client", …)`. Test files are excluded from `typecheck`.
- **e2e:** Playwright drives the production SPA against three real `tracelabel` server
  processes it spawns (ports 8399/8409/8419, each its own throwaway `--dir` workspace);
  it does not start Vite.

Before opening a PR: run both test suites and confirm the frontend builds.
